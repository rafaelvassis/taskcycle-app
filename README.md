# TaskCycle

Aplicação inspirada na técnica **Pomodoro**, desenvolvida para auxiliar na gestão do tempo através de ciclos de foco e descanso.

## Preview

![Demonstração do sistema](docs/demo.gif)

## Funcionalidades

- ⏱️ Temporizador de foco e descanso
- 📝 Gerenciamento de tarefas por ciclo
- 📜 Histórico de sessões
- 💾 Persistência local
- 🌙 Tema claro/escuro
- ⚙️ Configuração dos tempos dos ciclos
- 🔔 Notificações sonoras

## Tecnologias

- React
- TypeScript
- Vite
- Context API
- useReducer
- Web Workers
- CSS Modules

## O que aprendi

- Gerenciamento de estado com Context API e useReducer
- Comunicação entre React e Web Workers
- Organização de aplicações React em arquitetura modular
- Persistência de dados no navegador

## Executando o projeto

```bash
git clone https://github.com/rafaelvassis/taskcycle-app.git

cd taskcycle-app

npm install

npm run dev
```
